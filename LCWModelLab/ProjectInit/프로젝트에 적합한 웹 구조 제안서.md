
이찬울

GPTPilots 팀의 프로젝트는 RFP 문서에 대한 Q&A를 진행하는 RAG 시스템을 개발하는 프로젝트이다. 이에 맞는 웹 구조를 탐색해본다.

<시작하기 전에>

웹서비스를 구축하면 그에 대한 깃허브 레포지토리를 하나 더 생성해야합니다. 웹서비스는 일반적으로 용량이 매우 많이 나가며, 사용자 요청에 대해서 동적으로 AI 로직을 거쳐 답변을 생성하는 과정은 20G~30G의 용량을 예상합니다. 5명이 GCP VM 을 사용하여 웹서비스 프로젝트를 구동하게 되면 당연히 VM 한계 사용량에 도달하게 됩니다.

<Front-End>

프론트엔드는 React Framework를 추천한다. 문법이 어렵고 페이지를 넘어다니는 코드 때문에 힘들 수도 있지만, 인기있는 웹 서비스 기술(좋아요, 구독, 댓글 등)을 구현할 때 참고할 수 있는 문헌들이 많다. 문제는 React Framework는 사용자의 버튼 클릭과 키보드 입력에 항상 반응할 수 있는 반응형 웹을 만드는데 초점이 맞춰져 있어서, 항상 사용자의 입력을 받아들일 수 있는 Listen 상태가 유지되어야하고, React Framework는 자주 사용하는 개발자 로직들(디자인패턴)을 모듈화가 되어있기 때문에 용량이 많이 나간다. 또한, 일반적으로 리액트 프레임워크는 내부에 웹서버를 구동하는 로직이 있기 때문에, 모든 요소들을 포함하면 기본적으로 10G에 근접하거나 그 용량을 충분히 넘을 수 있다.

<Back-End>

백엔드는 필수는 아니다. 하지만 Q&A를 수행한 결과들을 편하게 보관하고 원하는 방식으로 React Framework에게 텍스트를 선별하여 보내주고 싶다면, Backend Framework를 선택할 가치가 있다. 만약 Q&A결과를 React Project Folder에 보관하여 참고하는 구조를 만든다면 백엔드는 없어도 된다. 백엔드는 DB + BackEnd Server 역할을 모두 수행할 수 있는 테스트용 백엔드 프레임워크, Firebase를 추천한다. 프론트엔드 웹을 연습할 때 단순한 백엔드 서버용으로 흔히 선택하는 프로그램이다. Firebase에 데이터를 넣어두면, React가 사용자 질문을 입력받은후 Firebase에 질문을 보내주고, 그 질문을 검색하여 대상 응답을 담은 파일을 찾으면 그 파일에서 답안 텍스트만 선별해서 React Framework에 보내줄 것이다. Firebase는 기능을 구현할 때 Javascript를 사용하기 때문에 프론트엔드를 연습할 때 자주 사용하는 프로그램이다. Firebase는 구글에서 제공하는 Serverless, NoSQL DB 플랫폼이다. 자바스크립트를 사용하면 리액트와 편하게 데이터를 주고받을수있다.

<Front-End Back-End 연동 구조>
보통 두 프레임워크를 연동시킬 때는 웹 서버 프로그램 끼리 Rest API를 설정한다. 그러나 Firebase는 이 설정을 firebaseconfig로 간편하게 설정할 수 있다. 우선 React Framework를 설치하고 프로젝트를 시작하면, npm을 이용하여 Firebase를 설치하면, 프로젝트 내부에 Firebase Module이 있게 된다. firebaseconfig를 설정하여, 외부의 React Framework와 통신을 주고받을 준비를 한다.

<전체 웹 구동>
우리는 VM을 100GB로 사용량을 제한하여 사용한다. 5명이 모두 같은 VM 서버를 사용하므로, 사용량이 한계에 도달하면 외부 GPU를 사용하지 못할 것으로 예상한다.(5명 모두 외장 그래픽카드가 없다.) VM으로 AI프로그램을 개발하고, 웹을 구동할 때는 개인 로컬에서 구동시킨다. VM에서 Q&A 결과를 json 파일로 만들어서 파일들을 Firebase에 저장한다. React가 사용자의 질문에 대한 응답으로 Firebase에 결과 텍스트를 요청하면, Firebase가 질문에 대한 응답을 json 파일들에서 검색해서 React로 보내주게 되고, React는 사용자에게 브라우저를 통해 답을 보여주게 된다. 우리는 편하게 질문에 대한 응답을 파일형태로 Firebase에 저장해두면 될 것이다.

<비용>
Firebase는 클라우드로 파일저장을 허용해줍니다. 무료버전은 1GB까지, 전송량은 10GB까지 허용해줍니다. 따라서 간단한 테스트를 수행하기 위해서 Firebase를 사용해야지, 여기에 무분별하게 데이터를 보관하면 추가 요금을 지불하는 문제가 생깁니다. Firebase는 Serverless 인데 클라우드로 동작하기 때문에 그렇습니다. NoSQL이지만 동작시킬 때는 JavaScript가 어느정도 필요하다는 것을 염두해두어야합니다. React는 전체 무료입니다.
