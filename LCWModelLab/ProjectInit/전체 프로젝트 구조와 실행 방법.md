<프론트엔드와 백엔드 통신 구조>

프론트엔드는 React Framework가, 백 엔드에는 Fast API Framework를 배치하여, 두 서버가 데이터 전송 및 응답을 통해 사용자는 임의의 질문에 대한 응답을 하는 서비스를 제공받는다. 개발의 편의성을 위해서, 프론트엔드는 로컬에서, 백엔드는 클라우드 환경에서 구동한다. 이에 따라 프론트엔드 개발은 로컬에서, 백엔드 개발은 VM에서 수행하는 것을 권장한다.

<백엔드 Fast-API 서버를 켜는 방법>

```bash
PYTHONPATH=. uv run uvicorn src.api.server:app --host 0.0.0.0 --port 8080
```

백엔드에서 Fast-API 서버를 켤 때는 호스트의 포트 번호를 명시하게 되어 있다. --port 이후 포트는 8000 ~ 9000 사이, VM 사용자들과 겹치지 않게 사용한다. (작성자는 8080입니다) 이것을 입력하고 Fast-API 서버를 켜게 되면 이제 Fast-API 서버는 데이터를 전송하거나 전달받을 상태, Active한 상태가 된고, Request에 대해 Response를 할 준비가 된다.

<프론트엔드 React 서버를 켜는 방법>

``` Powershell
npm run dev
```

이 명령어를 통해 프론트 엔드의 리액트 서버를 구동한다. 구동하기 전에 vscode에서 목적지 포트를 명시해주어야 한다. 우리는 프로젝트 초기에 vs code와 gcp vm을 원격 개발하는 방법에 대해 알았다. 이 방법을 모른다면 ==<concepts/# VS Code ↔ GCP VM 원격 개발 환경 연결 가이드>==를 참고한다.

vscode에서 목적지 포트를 명시하는 것은 remote ssh 앱을 통해 ssh 연결로 gcp vm의 fast api server와 연결하는 것이다. 물론 IP만 알면 GCP VM의 Fast API 백엔드 프로세스를 사용할 수 있게 하는 것이 배포이지만, 우리는 한정된 토큰을 사용해야 하고 트래픽이 높아지면 서버에 부하가 걸리기 때문에 ssh를 통해 일부 한정된 인원(Team GPTPilots)만 사용하기로 한다.
