
1. 프로젝트는 다양한 AI 모델을 활용하는데 학습 및 평가 비용이 많이 발생할 수 있으므로 Google Cloud Platform의 실행에 초점이 맞춰져 있다. 하지만 가벼운 테스트 환경이 필요하다면 로컬에서도 프로젝트를 실행할 수 있다. vscode와 git bash를 활용하여 프로젝트를 실행하여 본다.

2. 프로젝트 실행 순서

	ㄱ. github에서 로컬에 clone이나 pull을 하여 프로젝트를 로드한다.
	
	ㄴ. uv --version을 통해 uv 설치되어 있는지, 최신버전인지 확인한다.
	
	ㄷ. uv 가상환경을 세팅하기 전에, uv python install [프로젝트에 필요한 파이썬 버전] 을 입력하여 프로젝트에 맞는 파이썬 버전을 설치한다. 이 파이썬 버전은 uv run, uv venv와 같은 uv 명령어를 통해 파이썬 프로그램을 실행하는 경우에 로컬에 설치된 파이썬 버전과 다른 버전이다.
	
	ㄹ. uv venv 를 입력하여 uv 가상환경을 켜는데 초기화를 진행한다. 사용자에게 초기화를 하여야하는지 물어보면 'y'키를 누른다.
