
RFP : Request for Proposal (제안 요청서)
OCR : Optical Character Recognition (RAG에서는 문자 인식)

RFP 구성
1. 제안 요청 내용
2. 입찰 안내 사항
3. 제안서 작성 안내 사항
4. 평가 안내 사항

csv 헤더 종류
공고 번호, 공고 차수, 사업명, 사업금액, 발주기관, 공개일자, 입찰 참여 시작일, 입찰 참여 마감일, 사업 요약, 파일형식, 파일명, 텍스트

------

RFP 말고 용역 입찰 공고가 따로 있는 경우가 있음

ex) KUSF 체육특기자 경기기록 관리시스템 개발
