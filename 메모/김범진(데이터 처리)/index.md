## 검색 실험 — 시간순

검색 관련 문서가 일곱이라 순서가 헷갈리기 쉽다. **읽는 순서는 이렇다.**

```
① 검색 개선           검색을 언제 뭘 왜 고쳤나 (커밋 이력)
     ↓
② 검색 실험 골든셋 40문항   첫 평가셋을 사람이 만든 기록
     ↓
③ 골든셋               40 → 200 확장 · 라벨링 · 검증
     ↓
④ 검색 실험 계획 (164문항)   1차 실험을 왜 그렇게 설계했나
     ↓
⑤ 검색 실험 결과 (164문항)   ★ 1차 판정 — BM25 미채택 / 리랭커 채택
     ↓
⑥ 검색 2차 실험 계획        임베딩을 바꿔서 ⑤를 다시 검증 (§0-1 = 측정 조건 정본)
     ↓
⑦ 검색 2차 실험 결과        ★ 2차 판정 — e5 유지 / R1 유지 / BM25는 재측정 중
     ↑
     └─ 정답지 편향 제거      ⑦의 채점 기준을 고친 기록 (골든셋 v4 → v5)
```

**⑤가 채택 정본**이고, **⑦이 그걸 다시 재서 "그대로 둔다"로 끝난 결과**다.
①~④는 거기까지 온 과정, ⑥은 ⑦의 설계도, **정답지 편향 제거는 ⑦이 딛고 선 채점 기준**이다.

**두 차례 실험을 거쳐 지금 구성(e5-small + `bge-reranker-v2-m3`)이 그대로 남았다.**
단 **BM25만 판정이 반쪽이었던 것으로 드러나 다시 재고 있다** → [[검색 2차 실험 결과 (임베딩 교체)]] §3

### 1차 실험 결과 (e5-small 기준) — 현행 채택 구성

| 구성 | MRR@10 |
|---|---|
| dense 단독 (현행) | 0.6402 |
| + BM25 | 0.6096 ❌ |
| **+ 리랭커** | **0.7443 ✅ 채택** |

e5의 Recall@20 = **0.8163** — 정답의 18%가 후보 20개 밖에 있고, **17문항은 정답이 후보에 아예 없다**(리랭커로는 못 고침). 2차 실험의 명분.

### 2차 실험 결과 (임베딩 교체) — 값 정본은 [[검색 2차 실험 결과 (임베딩 교체)]] §1

**골든셋 v5 · 리랭커 R1 · `C_doc`**

| 임베딩 | MRR@10 | 기준선 대비 | 95% CI |
|---|---|---|---|
| **e5-small (현행)** | **0.7443** | 기준선 | — |
| bge-m3 | 0.7640 | +0.0197 | [−0.0151, +0.0578] |
| KURE-v1 | 0.7740 | **+0.0297** | **[−0.0042, +0.0654]** |

**→ 임베딩 교체 미채택, e5-small 유지.** 점추정은 KURE가 앞서지만 구간이 0을 품는다.
*"차이가 없다"가 아니라 **"이득이 증명되지 않는다"*** 다 — 재판정 조건 3개는 그 문서 §2-1.
R2 리랭커도 기각(점수 포화). **BM25는 후보 확장 효과를 안 잰 반쪽 판정으로 드러나 재측정 중** → 같은 문서 §3.

**+0.0068은 아직 개선폭이라 못 부른다** — 95% 신뢰구간 **[−0.029, +0.043]**이 0을 품는다.
정답지가 e5에 맞춰져 있어(새 모델은 상위 10개 중 **26~32%가 미판정**) 그 미판정 청크를 지금 직접 읽고 있다.
신규 정답률은 **2.0%(42/2,105)**로 낮지만 **점수는 그보다 크게 움직인다** — 7개만 반영해도 KURE +0.0078.

**→ 임베딩 교체는 판정 대기.** 전수 검증·병합·재채점 후 6.8.9에서 결정한다.

## 미해결

### 검색

- **거짓양성 미검사** — 모른다·반문 30문항에서 없는 근거를 지어내지 않는지 아직 안 봤다
- **탐색비교·후속 유형이 안 오른다** — 리랭커로 +0.034 / +0.005뿐. 여러 문서를 걸치는 검색은 별도 접근 필요
- **BM25 재측정 진행 중** — 지금까지의 기각은 **후보를 넓히는 효과를 안 잰 반쪽 실험**이었다. e5가 못 찾은 17문항 중 **11문항을 BM25가 건진다** → [[검색 2차 실험 결과 (임베딩 교체)]] §3
- **정답이 후보에 아예 없는 문항** — dense만으로는 e5 17 / KURE 9. 임베딩으로는 다 못 없앤다. 위 BM25 재측정이 이 영역을 겨냥한다
- **라벨링 보류 5건** — 사람 확인 대상. 쟁점은 표기 정규화(예: "3개월"과 "90일"을 같은 값으로 볼지) → [[정답지 편향 제거 (전체 풀링 라벨링)]] §5
- **KURE는 언제 다시 보나** — 지금은 기각이지만 조건 3개 중 하나면 재판정한다(골든셋 300문항↑ · 다른 이유로 재인덱싱 · Recall@20이 병목인 기능) → 같은 문서 §2-1
