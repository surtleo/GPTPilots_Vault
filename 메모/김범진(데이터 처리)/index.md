## 검색 실험 — 시간순

검색 관련 문서가 여섯이라 순서가 헷갈리기 쉽다. **읽는 순서는 이렇다.**

```
① 검색 개선           검색을 언제 뭘 왜 고쳤나 (커밋 이력)
     ↓
② 검색 실험 골든셋 40문항   첫 평가셋을 사람이 만든 기록
     ↓
③ 골든셋               40 → 200 확장 · 라벨링 · 검증
     ↓
④ 검색 실험 계획 (164문항)   1차 실험을 왜 그렇게 설계했나
     ↓
⑤ 검색 실험 결과 (164문항)   ★ 1차 판정 — BM25 미채택 / 리랭커 채택
     ↓
⑥ 검색 2차 실험 계획        임베딩을 바꿔서 ⑤를 다시 검증 (§0-1 = 측정 조건 정본)
     ↓
⑦ 검색 2차 실험 결과        ★ 2차 판정 — BM25 최종 기각 / R1 유지 / 임베딩 교체 미채택
```

**⑤가 채택 정본**이고, **⑦이 그걸 다시 재서 재확인한 결과**다. ①~④는 거기까지 온 과정, ⑥은 ⑦의 설계도다.
**두 차례 실험을 거쳐 지금 구성(e5-small + `bge-reranker-v2-m3`)이 그대로 남았다.**

### 1차 실험 결과 (e5-small 기준) — 현행 채택 구성

| 구성 | MRR@10 |
|---|---|
| dense 단독 (현행) | 0.6402 |
| + BM25 | 0.6096 ❌ |
| **+ 리랭커** | **0.7443 ✅ 채택** |

e5의 Recall@20 = **0.8163** — 정답의 18%가 후보 20개 밖에 있고, **17문항은 정답이 후보에 아예 없다**(리랭커로는 못 고침). 2차 실험의 명분.

### 2차 실험 결과 (임베딩 교체) — 값 정본은 [[검색 2차 실험 결과 (임베딩 교체)]]

| 임베딩 | dense 단독 | + R1 리랭커 |
|---|---|---|
| M0 e5-small (현행) | 0.6402 | **0.7443** ← 기준선 |
| M1 bge-m3 | 0.7417 | 0.7412 |
| M2 KURE-v1 | 0.7416 | **0.7511** |

**dense 단독으로는 +0.10, 리랭커를 켜면 +0.0068.** 임베딩 교체 이득을 리랭커가 거의 흡수한다.
BM25는 세 임베딩 전부에서 순손해(**최종 기각**), 한국어 튜닝 리랭커 R2는 점수 포화로 크게 진다(**R1 유지**).

**+0.0068은 개선폭이 아니다** — 95% 신뢰구간 **[−0.029, +0.043]**으로 우연 범위다.
정답지가 e5에 맞춰져 있어(새 모델은 상위 10개 중 **26~32%가 미판정**) 판정을 한 번 유보했으나,
그 미판정 청크 **530개를 실제로 라벨링해보니 진짜 정답은 1.3%**뿐이었다 — 상한이 허수였다.

**→ 임베딩 교체 미채택. 현행 `M0 + R1` 유지.**

## 미해결

### 검색

- **거짓양성 미검사** — 모른다·반문 30문항에서 없는 근거를 지어내지 않는지 아직 안 봤다
- **탐색비교·후속 유형이 안 오른다** — 리랭커로 +0.034 / +0.005뿐. 여러 문서를 걸치는 검색은 별도 접근 필요
- **증분 라벨링을 전수로 갈지 미정** — shard1 530개(전체 2,105개의 25.2%)만 판정한 표본 추정이다. 나머지 3샤드 전수 판정 여부는 **사용자 결정 대기** → [[검색 2차 실험 결과 (임베딩 교체)]] §8-5
- **라벨링 보류 3건** — 사람 확인 대상. 쟁점은 표기 정규화(예: "3개월"과 "90일"을 같은 값으로 볼지). 3건이 다 뒤집혀도 결론은 안 바뀐다
- **정답이 후보에 아예 없는 문항이 13개 남았다** — 임베딩을 키워 17 → 13으로 줄었을 뿐이다. 리랭커로는 못 고치는 영역

### 그 밖

- **자격요건 재추출이 왜 98건인가** — 문서 100 / chunks 99 / 자격요건 98. 마지막 1건 기록 없음 → [[참가자격 매칭 구조 정리]]
- **전건 재추출이 팀 공용 키($20)를 쓰는가** — [[청킹 표 처리 수정 (Phase 11)]]은 팀 합의 대상으로 두고 동결. 자격요건 쪽도 같은 성격인지 미확인
- **적합도 "상/중/하" 정의 미합의** — 이것 때문에 웹 화면 3개가 블록 → [[BidMate 웹 연동 현황]]
- **볼트 공개 범위** — Quartz `ignorePatterns`가 `메모/`를 제외하지 않는다. gh-pages로 배포하면 RFP 발췌가 있는 문서가 공개된다
