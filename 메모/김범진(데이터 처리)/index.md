## 미해결 — 확인이 필요한 것

- **자격요건 재추출이 왜 98건인가** — 문서 100 / chunks 99 / 자격요건 98. 마지막 1건이 왜 빠졌는지 기록이 없다. 팀원 정답지와 건수 기준이 다르면 대조에서 "누락"으로 오판될 수 있다 → [[참가자격 매칭 구조 정리]]
- **전건 재추출이 팀 공용 키($20 한도)를 쓰는가** — [[청킹 표 처리 수정 (Phase 11)]]에서는 전건 재추출을 팀 합의 대상으로 두고 `--adopt`로 동결했다. 자격요건 쪽도 같은 성격인지 미확인
- **골든셋 200문항 라벨링·검증 완료 여부** — 생성은 확인됐으나 그다음은 미확인. v8 성적 0.8375로 **아직 합격선 미달**
- **`retrieve.py:36`의 `and doc_id is None`** — 실측상 거꾸로 걸려 있다. 수정 전 라우터 문서 판정 정확도 측정이 선행돼야 함 → [[검색 개선]]
- **적합도 "상/중/하" 정의 미합의** — 이것 때문에 웹 화면 3개가 블록돼 있다 → [[BidMate 웹 연동 현황]]
