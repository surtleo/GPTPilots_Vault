## 검색 실험 — 시간순

검색 관련 문서가 다섯이라 순서가 헷갈리기 쉽다. **읽는 순서는 이렇다.**

```
① 검색 개선           검색을 언제 뭘 왜 고쳤나 (커밋 이력)
     ↓
② 검색 실험 골든셋 40문항   첫 평가셋을 사람이 만든 기록
     ↓
③ 골든셋               40 → 200 확장 · 라벨링 · 검증
     ↓
④ 검색 실험 계획 (164문항)   1차 실험을 왜 그렇게 설계했나
     ↓
⑤ 검색 실험 결과 (164문항)   ★ 1차 판정 — BM25 미채택 / 리랭커 채택
     ↓
⑥ 검색 2차 실험 계획        임베딩을 바꿔서 ⑤를 다시 검증
```

**⑤가 현행 정본**이다. ①~④는 거기까지 온 과정이고, ⑥이 다음 할 일이다.

| 문서 | 답하는 것 | 상태 |
|---|---|---|
| [[검색 개선]] | 검색 변경 이력 + 1차 BM25 실험 전 과정 | ⚠️ 2부 결론은 ⑤에서 뒤집힘 |
| [[검색 개선 스토리보드]] 🖼 | 골든셋 40 → 청킹 → 메타 → BM25 **인과 서사** | |
| [[검색 실험 골든셋 40문항]] | 40문항 라벨링·감사, **문항 전체 목록** | 사료 |
| [[골든셋]] | 40→200 확장 설계 · 라운드별 성적 (**성적 정본**) | 현행 |
| [[골든셋 200문항 제작]] | 200문항을 실제로 어떻게 뽑았나 | 현행 |
