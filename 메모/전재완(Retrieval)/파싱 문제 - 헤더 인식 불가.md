헤더 주제를 인식 못하고 일반 텍스트로 인식 

hwp_hwpx_parser가 애초에 `#` 헤더를 만들어낼 방법 자체가 없음

-> 글자 크기를 통해 판별 

**지금(Before)**:

```
| Ⅰ. 사업개요 |
| --- |


| 1 |  | 사업일반 |
| --- | --- | --- |

□ 사 업 명 : 통합 정보시스템 구축 사전 컨설팅
```

**바뀐 뒤(After)**:

```
# Ⅰ. 사업개요

## 1. 사업일반

□ 사 업 명 : 통합 정보시스템 구축 사전 컨설팅
```

1. **원본 hwp 파일을 한 번 더 열어서** (지금 쓰는 라이브러리 말고 `pyhwp`라는 다른 도구로) 문단마다 "글자 크기가 몇 pt인지"를 읽음 .  본문보다 훨씬 큰 글자(예: 20pt)로 써진 문단만 "제목 후보"로 뽑음
2. **이미 뽑아놓은 markdown 텍스트에서 그 제목 후보 글자를 찾아서** 앞에 `#`을 붙여줌
	표 안에 갇힌 1칸짜리 제목("| Ⅰ. 사업개요 |")은 표를 없애고 그냥 `# Ⅰ. 사업개요`로 바꿈

즉 기존 추출 결과(표·본문)는 그대로 두고, "이 줄은 제목이다"라는 표시만 나중에 덧붙이는 방식이라 지금 잘 작동하는 부분을 건드리지 않음 

실패 파일 
1. **한국농어촌공사 아세안** — CLAUDE.md에 이미 기록된 그 파일. `pyhwp`가 이 파일 특정 구간에서 제어문자 에러로 죽음. 본문 추출 자체는 멀쩡하고, 헤더 보강만 조용히 스킵됨(에러 안 퍼짐, 확인함).
2. **대전대학교(MILE 플랫폼)** — 새로 발견. 이 파일 안에 깨진 UTF-16 문자가 하나 박혀있어서 `pyhwp`가 파싱하다 죽음. 마찬가지로 본문은 멀쩡, 헤더만 스킵.
