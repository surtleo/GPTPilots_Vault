## 4. 검증 항목

### 끝난 것

- [x] **참가불가 규칙 오탐 검사** (라운드 6, $0)
      `knockout_kind()`를 실제 import해 1,703요건 전수 통과. 검출 대기업집단 128 / 부정당업자 49.
      의심 문장 20종 전수 판독 → **오탐 0**.
- [x] **되묻기 매핑 전수 분석** (라운드 6, $0)
      미매칭 25%(정상, 커버리지 75%와 일치) · 정확히 1개 매칭 52% · 2개 이상 23%.
      키워드 부분문자열 충돌 없음.

### 남은 것 (우선순위 순)

- [ ] **혼합 문장이 실제로 오탐을 만드는지** (유료, 판정 1~2회)
      "대기업 참여 불허, 공동수급 및 하도급 불가"처럼 한 문장에 여러 조건이 섞인 요건 8건.
      대기업 아닌 회사 프로필로 그 문서를 판정해 참가불가가 잘못 뜨는지 확인.
- [ ] **소재지가 실제 판정에 반영되는지** (유료, 판정 2회)
      지역제한 조항이 있는 5개 문서 중 하나로, 본점을 맞게/틀리게 넣어 판정이 갈리는지.
      (지역제한 문서: 부산관광공사 · 광주연구원 · 정읍시 · 부산국제영화제 · 구미 아시아육상)
- [ ] **면허 항목이 실제 판정에 반영되는지** (유료, 판정 2회)
      정보통신공사업을 요구하는 문서(7건 중 하나)로 체크/미체크 비교.
- [ ] **프로필 v2(21개) vs 기존(5개) 다문서 비교** (유료)
      확인율이 실제로 오르는지 문서 3~4개로. 라운드 6 이전엔 1개 문서로만 봤음.
- [ ] **프론트가 진짜 `search_text`를 보내는지** ($0 시도)
      uvicorn 기본 로그는 요청 바디를 안 남김. 빌드 산출물(dist)에서 확인하거나
      다른 우회 방법 시도. 못 하면 "확인 불가"로 남기고 회원님께 부탁.
- [ ] **아직 안 읽은 코드** ($0)
      `chat/cards.tsx` 리포트 카드가 불명 21건을 그대로 그리면 카드가 너무 길어지지 않는지.
      `viewer/compare-table.tsx`가 새 필드(unclear·blocking)로 깨지지 않는지.
- [ ] **추천 경로와 준비점검 경로의 응답 일관성** (유료 — 추천은 비싸므로 마지막에)
