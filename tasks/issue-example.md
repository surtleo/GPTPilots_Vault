# 1 이슈 제목 예시

> 이 파일은 예시 템플릿입니다. GitHub 이슈와 동기화되는 `tasks/issue-{N}.md` 파일의 frontmatter 구조를 보여줍니다.
>
> - `issue`: GitHub 이슈 번호
> - `title`: `[label] 제목` 형식
> - `assignee`: GitHub ID (단일 문자열 또는 리스트)
> - `label`: 이슈 라벨 (예: data, train, infer, setup)
> - `st`: 상태 — todo / doing / done
> - `milestone`: 마일스톤 (예: v0.1, v0.2)
> - `priority`: 우선순위 — p1 / p2 / p3
> - `target`: 마감일 (YYYY-MM-DD)
> - `github`: GitHub 이슈 URL
>
> 본문에는 작업 노트·실험 기록 등을 자유롭게 작성합니다.
> 상태 업데이트는 `st:` 필드만 수정하면 됩니다.
