### [2] 오늘 맡은 역할 및 구체적인 작업 내용

> 오늘 당신이 맡았던 역할은 무엇이었고, 어떤 작업을 수행했나요?

<span style="color:#aaa; font-style:italic">예시) 데이터 전처리 파트 담당. 범주형 변수 인코딩 및 이상치 확인 코드 작성 후 팀에게 공유함.</span>

✍️ 답변:

```
검색 쪽을 통째로 손봤다.
- 한국어 BM25 검색(kiwipiepy 형태소) + 토큰 캐시, RRF 융합 함수 추가
- 크로스인코더 리랭커 붙이고 실패하면 원래 순위로 폴백
- dense / BM25 / 리랭커 / 하이브리드 4변형을 같은 조건에서 비교하는 측정 러너
- 청크 단위 순위 지표(MRR·nDCG·Recall) 추가
- 표 게이트를 '검증'에서 '정규화'로 교체 — 병합셀 표 빈칸을 채운 뒤 표 청크로 만들게 함
- 표 셀 안 섹션 제목을 헤더로 승격(hwp 제목 상자 1칸, 번호+제목 2칸 조건부)
- 골든셋 40문항으로 확장, 라벨링 스크립트에 자동 제안(--review) 추가
- 공고 카드 조회 API(GET /rfps, /rfps/{doc_id})
```
